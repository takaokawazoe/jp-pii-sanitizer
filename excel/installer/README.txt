PII サニタイザ Excel アドイン

配布 zip の excel\ フォルダに、Excel アドイン一式が入っています。
検知モデルは 1 つ上の models\ を GUI / CLI と共有しています（excel\ だけ切り出して
別の場所に置くと動きません）。入れ方は 2 通りあります。

■ A. インストーラで入れる（おすすめ）
  excel\jp-pii-sanitizer-excel-setup.exe を実行します。管理者権限は要りません。
  インストーラがやること:
    - %LOCALAPPDATA%\jp-pii-sanitizer\ に、このフォルダの中身と models\ をコピーする
    - そのフォルダを Excel の「信頼できる場所」（現在のユーザーのみ）に登録する
      → 未署名のアドインでも、Excel の起動ごとの「セキュリティの通知」が出ません
    - Excel の起動時にアドインを読み込むよう登録する
  終わったら Excel を起動してください。リボンに「PII」タブが出ます。
  インストール後は、展開した zip のフォルダを消しても構いません。

  setup.exe は単体では動きません。zip を展開した excel\ フォルダの中で実行してください。
  未署名のため「Windows によって PC が保護されました」と出ることがあります。
  ［詳細情報］→［実行］で進めます。
  無人インストール:  jp-pii-sanitizer-excel-setup.exe /VERYSILENT /SUPPRESSMSGBOXES

  やめるとき: 設定 → アプリ → 「PII サニタイザ Excel アドイン」をアンインストール。
  登録も外れます。列の記憶（excel-column-rules.json）だけ残るので、不要なら削除してください。

■ B. インストーラを使わない（手動で登録する）
  1. zip を展開したフォルダごと、消さない場所に置きます（例: %LOCALAPPDATA%\jp-pii-sanitizer\）。
     インターネットから落とした zip は、展開する前に
       zip を右クリック → プロパティ → 「ブロックの解除」にチェック → OK
     をしておくと確実です（PowerShell なら Unblock-File <zip>）。
  2. Excel → ファイル → オプション → トラストセンター → トラストセンターの設定 →
     信頼できる場所 → 新しい場所の追加 → この excel\ フォルダを選ぶ → OK
     これを省くと、Excel を起動するたびに「セキュリティの通知」が出ます。
  3. Excel → ファイル → オプション → アドイン → 画面下の 管理:「Excel アドイン」→ 設定 →
     参照 → この excel\ フォルダの jp-pii-sanitizer.xll を選ぶ → OK
     リボンに「PII」タブが出れば完了です。
     （1 回だけ使うなら、ファイル → 開く で jp-pii-sanitizer.xll を開くだけでも動きます）
  やめるとき: 手順 3 の一覧でチェックを外す → 手順 2 の一覧から削除 → フォルダを削除。

■ 使い方
  1. リボンの「PII」タブ → 「サニタイズ」でタスクペインが開きます
     読み込んで検出 → 列の扱いを確認 → サニタイズして別ブックに保存
     サニタイズ済みのブックは別ファイルとして保存され、元のブックは変わりません。
  2. 「実名に戻す」で、AI の返答（文章）や、AI が返した表を貼ったシートを実名に戻せます

■ 対応表について（重要）
  可逆モードでは、サニタイズ済みブックの隣の「対応表」フォルダに
  <ブック名>.jsonl ができます。これは実名とトークンの対応そのものです。
    - AI には絶対に渡さないでください（添付する .xlsx を選ぶ一覧には並びません）
    - 不要になったら削除してください
    - 「パスフレーズで保護」を付けると暗号化されます。パスフレーズを失うと戻せません

■ 覚える情報
  見出し → 列の扱い の対応だけを
    %LOCALAPPDATA%\jp-pii-sanitizer\excel-column-rules.json
  に記憶し、次に同じ見出しの表を読んだときの提案に使います。セルの値は書きません。

■ 動作環境
  Windows 11 以降、64 ビット版の Excel（Microsoft 365 / Office 2016 以降）。
  ネットワークは使いません。
  初回の「読み込んで検出」はモデルの読み込みに十数秒かかり、約 1 GB のメモリを使います。

■ 注意
  本ツールは検出した PII をマスクしますが、すべての PII の除去を保証するものではありません。
  既定は全マスク（opt-out）ですが、社内 AI 等へ送信する前に必ず内容をご確認ください。
