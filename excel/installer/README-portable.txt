PII サニタイザ Excel アドイン（ポータブル版・インストーラ不要）

この zip には、インストーラ版とまったく同じファイルが入っています。
インストーラがやっている 3 つのこと（ファイルを置く／信頼できる場所に登録する／
Excel の起動時に読み込ませる）を手作業で行います。管理者権限は要りません。

■ 1. ブロックの解除（展開する前に）
  インターネットからダウンロードした zip をそのまま展開すると、中のファイルに
  「インターネットから取得した」印が付き、Excel は XLL を読み込みません。
    zip を右クリック → プロパティ → 全般タブの下にある「ブロックの解除」にチェック → OK
  これを**展開する前に**行ってください。
  （PowerShell なら:  Unblock-File .\jp-pii-sanitizer-excel-*-portable.zip ）
  手順 3 の「信頼できる場所」に置けば印が付いていても読まれますが、解除しておくのが確実です。

■ 2. 展開
  書き込みできるフォルダに展開します。おすすめ:
    %LOCALAPPDATA%\jp-pii-sanitizer\
  （エクスプローラのアドレス欄に %LOCALAPPDATA% と入れると開きます）
  次のファイルが同じフォルダに揃っていれば、場所はどこでも構いません:
    jp-pii-sanitizer.xll   jp-pii-helper.exe   onnxruntime.dll
    onnxruntime_providers_shared.dll   models\（フォルダごと）
  XLL はヘルパーとモデルを自分の隣から探します。

■ 3. 信頼できる場所に登録
  Excel → ファイル → オプション → トラストセンター → トラストセンターの設定 →
  信頼できる場所 → 新しい場所の追加 → 手順 2 のフォルダを選び、
  「この場所のサブフォルダーも信頼する」にチェック → OK
  これを省くと、未署名のアドインなので Excel を起動するたびに
  「セキュリティの通知」が出て、都度「有効にする」を押すことになります。

■ 4. アドインとして登録（毎回自動で読み込む）
  Excel → ファイル → オプション → アドイン → 画面下の 管理:「Excel アドイン」→ 設定 →
  参照 → 手順 2 のフォルダの jp-pii-sanitizer.xll を選ぶ → OK
  リボンに「PII」タブが出れば完了です。
  （1 回だけ使うなら、ファイル → 開く で jp-pii-sanitizer.xll を開くだけでも動きます）

■ やめるとき
  アドインの一覧（手順 4 の画面）でチェックを外す → フォルダを削除 →
  信頼できる場所（手順 3 の画面）から削除。
  %LOCALAPPDATA%\jp-pii-sanitizer\excel-column-rules.json（列の記憶）も不要なら削除。

■ 使い方
  1. リボンの「PII」タブ → 「サニタイズ」でタスクペインが開きます
     読み込んで検出 → 列の扱いを確認 → サニタイズして別ブックに保存
     サニタイズ済みのブックは別ファイルとして保存され、元のブックは変わりません。
  2. 「実名に戻す」で、AI の返答（文章）や、AI が返した表を貼ったシートを実名に戻せます

■ 対応表について（重要）
  可逆モードでは、サニタイズ済みブックの隣の「対応表」フォルダに
  <ブック名>.jsonl ができます。これは実名とトークンの対応そのものです。
    - AI には絶対に渡さないでください（添付する .xlsx を選ぶ一覧には並びません）
    - 不要になったら削除してください
    - 「パスフレーズで保護」を付けると暗号化されます。パスフレーズを失うと戻せません

■ 覚える情報
  見出し → 列の扱い の対応だけを
    %LOCALAPPDATA%\jp-pii-sanitizer\excel-column-rules.json
  に記憶し、次に同じ見出しの表を読んだときの提案に使います。セルの値は書きません。

■ 動作環境
  Windows 11 以降、64 ビット版の Excel（Microsoft 365 / Office 2016 以降）。
  ネットワークは使いません。検知モデルは models\ にあります。
  初回の「読み込んで検出」はモデルの読み込みに十数秒かかり、約 1 GB のメモリを使います。

■ 注意
  本ツールは検出した PII をマスクしますが、すべての PII の除去を保証するものではありません。
  既定は全マスク（opt-out）ですが、社内 AI 等へ送信する前に必ず内容をご確認ください。
